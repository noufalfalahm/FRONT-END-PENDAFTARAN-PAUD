# FRONT-END-PENDAFTARAN-PAUD

Antarmuka *front-end* untuk sistem pendaftaran online Pendidikan Anak Usia Dini (PAUD), dirancang untuk memudahkan proses pendaftaran peserta didik baru secara digital menggunakan Laravel dan Tailwind CSS.

## Fitur
- Halaman Beranda / Informasi Pendaftaran
- Formulir Pendaftaran Peserta Didik Baru
- Dashboard & Manajemen Data Pendaftar
- Detail Pendaftar

## Teknologi yang Digunakan
- **Framework:** Laravel
- **Styling:** Tailwind CSS
