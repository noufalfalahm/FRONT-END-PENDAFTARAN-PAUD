# FRONT-END-PENDAFTARAN-PAUD

Antarmuka *front-end* untuk sistem pendaftaran online Pendidikan Anak Usia Dini (PAUD), dirancang untuk memudahkan proses pendaftaran peserta didik baru secara digital menggunakan Laravel dan Tailwind CSS.

## Fitur
- Halaman Beranda / Informasi Pendaftaran
- Formulir Pendaftaran Peserta Didik Baru
- Dashboard & Manajemen Data Pendaftar
- Detail Pendaftar

## Teknologi yang Digunakan
- **Framework:** Laravel 
- **Styling:** Tailwind CSS

🖼️ Preview Antarmuka (UI/UX Showcase)
Hasil implementasi antarmuka front-end sistem pendaftaran online Pendidikan Anak Usia Dini (PAUD) yang dirancang secara modern dan responsif.

🌟 Keunggulan Desain & Fitur Utama:
Desain Responsif & Modern: Dibangun menggunakan utilitas kelas Tailwind CSS yang memastikan tampilan tetap optimal, rapi, dan adaptif di berbagai ukuran perangkat (desktop hingga mobile).

Navigasi Intuitif (CTA): Menyediakan tombol Call-to-Action (CTA) yang menonjol untuk memudahkan calon pendidik atau orang tua melakukan navigasi instan ke formulir pendaftaran.

Formulir Pendaftaran Interaktif: Dilengkapi dengan field input form yang bersih, terstruktur, serta panduan singkat untuk memudahkan pengisian data calon peserta didik baru.

Dashboard & Manajemen Data Real-Time: Dilengkapi panel ringkasan data untuk memudahkan pihak admin memantau statistik pendaftar secara cepat dan efisien.
